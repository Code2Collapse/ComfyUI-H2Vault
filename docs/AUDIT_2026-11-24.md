## 7. Roadmap claims that are wrong or imprecise

1. `tests/test_v8_zero_information.py` does not exist; the file is `tests/test_v8_zero_info.py`.
2. "`web/js/_h2v_previews_ui.js` has a basic video player with native controls" - wrong file: `_h2v_previews_ui.js` is the author's settings section (`previewSection`); the player is `web/js/h2vault_previews.js:mediaEl`.
3. "Up to ten named authenticators" - correct (`MAX_AUTHENTICATORS = 10`, since 41ae6e3), but a constant, not configurable.
4. "`begin_enrolment()` generates recovery codes only when none remain" - correct; not mentioned: codes are created before the code check, stored on confirm, and a 15-minute pending setup reuses its codes.
5. "`start()` processes the missing-model list sequentially" - correct.
6. "C2C migration is a backlog item in `docs/ARCHITECTURE.md`" - correct.
7. "Argon2id" for the secrets file - correct that it is not used there (PBKDF2 200k + Fernet); Argon2id is already used in `crypto.kek_from_password`, `workflow_encrypt` and `licence.export_author`.
8. Part 2C list of current combinations - accurate; not stated: Advanced is OR-only, recovery codes cannot be excluded, no per-authenticator binding.
9. 2A "a code from ANY authenticator registered and authorized for that vault" - imprecise: a vault authorizes the method, i.e. every app of the installation.
10. Item 4 misses two facts: the author key already has Argon2id export/import to reuse, and a failed secret read regenerates the installation key (`secrets_store.get` -> `keys.install_private_key`), a data-loss risk.
11. Item 1 understates one gap: besides concealment's `install()` returning True, the vault filter underneath fails OPEN on an exception (`protected_subgraph.install_message_filter` send_sync / task_done log and pass the unfiltered data).
12. Item 2 misses one gap: the old address check let 100.64.0.0/10 (shared / CGNAT) through (`is_private` is False for it on Python 3.12.13, measured), and an environment proxy bypassed the DNS check entirely.
13. Item 3 / 4D understates: hosted failure only logged (fixed on this branch), `/ws` not covered, `local_only` routes refuse remote hosted customers for provisioning and installs.
14. Item 12 "reuse `check_public` and the recipient preview" - both exist (`routes.conceal_check`, `_h2v_conceal.js:renderPreview`) but only for concealed vaults.
